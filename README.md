## Who We Are

Red Matcha is a team of certified offensive-security practitioners delivering
penetration testing and red-team engagements across the full attack surface:
web and mobile applications, APIs, internal and external networks,
infrastructure, and cloud. We test the way real adversaries operate, mapping the
gap between design intent and implementation reality, then proving impact with
reproducible, evidence-backed findings.

Every engagement is scoped, authorized, and reported against recognized
industry standards, with clear remediation guidance and re-test support.

## Services

| Domain | What we assess |
| --- | --- |
| **Web Application** | OWASP Top 10 / ASVS-aligned testing, authentication &amp; session flaws, access-control (BOLA/IDOR/BFLA), injection, business-logic abuse |
| **Mobile Application** | Android &amp; iOS testing per OWASP MASVS/MASTG: RASP &amp; anti-tamper review, SSL-pinning bypass, local storage, reverse engineering, runtime instrumentation |
| **API** | REST/GraphQL testing per OWASP API Security Top 10, authorization matrix sweeps, schema/enumeration oracles, rate-limit and mass-assignment abuse |
| **Network &amp; Infrastructure** | External &amp; internal network penetration testing, Active Directory attack paths, lateral movement, privilege escalation, configuration review |
| **Red Teaming** | Goal-oriented adversary simulation, initial access, C2 &amp; evasion, MITRE ATT&amp;CK-mapped TTPs, detection &amp; response validation (purple-team option) |

## Methodology &amp; Standards

We align engagements to established frameworks so results are consistent,
comparable, and defensible in a tender or audit context:

- **OWASP** WSTG (Web Security Testing Guide), ASVS (Application Security
  Verification Standard), and API Security Top 10
- **OWASP MASVS / MASTG** for mobile application security verification and testing
- **PTES**, the Penetration Testing Execution Standard
- **NIST SP 800-115**, Technical Guide to Information Security Testing
- **MITRE ATT&amp;CK** for adversary TTP mapping in red-team engagements
- **CVSS v3.1 / v4.0** for severity scoring across all findings

**Engagement flow:** Scoping &amp; Authorization, Reconnaissance &amp; Enumeration,
Exploitation &amp; Post-Exploitation, Impact Validation, Reporting, and
Remediation Re-test.

Every finding is delivered with its root cause, reproduction steps, proof
(request/response, PoC, or screenshots), business impact, and prioritized
remediation.
